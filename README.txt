SOUTHERN WATERS — 3D PLAYABLE PROTOTYPE
======================================

This is a real-time WebGL 3D browser prototype using Babylon.js. It is not a static screenshot.
It includes a first-person 3D lakeside environment, joystick movement, drag-to-look controls,
a visible rod/line/float, cast → bite → reel/fight → catch/reward loop, basic boat mode,
water selection, in-game currency and a simple rod upgrade.

RUN IT
------
1. Upload index.html to the root of your GitHub Pages repository (or upload the whole folder).
2. Open the published HTTPS GitHub Pages URL on the iPhone.
3. Rotate the phone to landscape. The 3D game is hidden in portrait and shows a rotate prompt.
4. Tap Start Fishing.

IMPORTANT LIMITATIONS
---------------------
- Babylon.js is loaded from its official CDN, so the page needs internet access.
- This is an early gameplay prototype, not a finished AAA game or native App Store app.
- Water-body species are provisional placeholders for gameplay and are explicitly not a verified
  species catalogue. Before a public release, the species list, legal access, permits, catch limits,
  boat rules, and fish sizes must be researched against authoritative South African sources.
- 3D terrain/trees are procedural primitives, not photogrammetry or custom high-detail assets.
- Touch controls and gameplay code have not been physically tested on the user's iPhone in this
  environment. Test on the published HTTPS page; device-specific bugs may need another iteration.

NO PAID SERVICES REQUIRED
-------------------------
The HTML can be hosted free on GitHub Pages. Babylon.js CDN delivery requires network access.

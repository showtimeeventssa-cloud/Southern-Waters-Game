SOUTHERN WATERS M9 — PLAYABLE FISHING PROTOTYPE
New playable session includes animated canvas water/shore/sky, first-person rod and fishing line, bank movement, boat mode/steering, casting, bite timing, hook setting, line tension, fish fight, catch landing, and in-game cash rewards.
Open via GitHub Pages HTTPS in Safari. Use landscape orientation.
Touch controls: directional pad to move/steer; CAST; REEL IN; BOAT toggle. Wait for the float to change colour and the BITE message, then tap REEL IN to set the hook. Keep reeling while watching tension; high tension can snap the line. Tap LAND FISH / KEEP CATCH to earn cash.
This is a playable 2D prototype, not a finished AAA 3D simulator. Fish/location roster is a starter game roster and should be validated against fisheries data before claiming exhaustive species accuracy.
